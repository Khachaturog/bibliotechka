# Скрытие meta-полей (строки 166–170)

## Что скрываем

Поля в блоке `.detail-meta` в [detail.html](detail.html):

- Раздел (`.group-slug`)
- Теги (`.detail`)
- Категория (`.subgroup-slug`)
- Появилось в версии (`.version-slug`)
- Статус (`.status-slug`)

## Подход

Использовать CSS-селектор `:has()` — находим строки по классу span со значением и скрываем их. HTML и JS трогать не нужно.

## Изменения

**Файл:** [css/base.css](css/base.css)

После правила `.detail-meta-row span:last-child` (строка ~1806) добавить:

```css
/* TODO: убрать когда придумаешь применение этих полей */
.detail-meta-row:has(.group-slug),
.detail-meta-row:has(.detail),
.detail-meta-row:has(.subgroup-slug),
.detail-meta-row:has(.version-slug),
.detail-meta-row:has(.status-slug) {
  display: none;
}
```

## Возврат в будущем

Удалить добавленное правило из [css/base.css](css/base.css).

## Совместимость

`:has()` поддерживается во всех современных браузерах (Chrome 105+, Safari 15.4+, Firefox 121+).
