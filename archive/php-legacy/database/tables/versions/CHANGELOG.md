# Changelog - Таблица `versions`

## [2025-12-09]

### Изменено
- ✅ Добавлена связь с таблицей `data` через внешний ключ `fk_data_version`
- ✅ `data.version_slug` → `versions.slug` (ON DELETE SET NULL, ON UPDATE CASCADE)
- **Причина:** Связывание элементов с версиями для отслеживания, в какой версии был добавлен/изменён элемент

## [2025-12-09] - Первоначальная версия

### Создано
- Таблица `versions` создана
- Добавлены поля для хранения информации о версиях проекта
- `slug` как PRIMARY KEY
- Поля для версии, названия, описания, даты релиза и ссылки
- Автоматические timestamps: `created_at_db`, `updated_at_db`

### Структура
- `slug` - уникальный идентификатор версии (PRIMARY KEY)
- `version` - номер версии (например, 5.0, 4.1)
- `title` - название версии
- `description` - подробное описание изменений (TEXT для длинных описаний)
- `release_date` - дата релиза
- `url` - ссылка на анонс/пост о версии
