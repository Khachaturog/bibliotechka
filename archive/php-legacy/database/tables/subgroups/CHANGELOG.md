# Changelog - Таблица `subgroups`

## [2025-12-19]

### Изменено
- ✅ Изменено поведение при удалении группы: вместо каскадного удаления подгрупп (`ON DELETE CASCADE`), поле `group_slug` теперь устанавливается в `NULL` (`ON DELETE SET NULL`)
- ✅ Колонка `group_slug` теперь разрешает `NULL` значения
- **Причина:** Сохранение подгрупп при удалении группы для возможности восстановления или переназначения группы

## [2025-12-09]

### Изменено

- ✅ Переименована колонка `title` → `title_ru`
- ✅ Переименована колонка `description` → `description_ru`
- ✅ `slug` теперь PRIMARY KEY (уникальный, без проверки на title)
- ✅ Заполнено поле `title_en` значениями из `slug`
