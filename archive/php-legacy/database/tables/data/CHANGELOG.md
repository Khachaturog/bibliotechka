# Changelog - Таблица `data`

## [Unreleased]

### Планируется
- Возможные изменения структуры для поддержки мультиязычности

## [2025-12-19]

### Изменено
- ✅ Изменено поведение при удалении группы: вместо каскадного удаления карточек (`ON DELETE CASCADE`), поле `group_slug` теперь устанавливается в `NULL` (`ON DELETE SET NULL`)
- ✅ Изменено поведение при удалении подгруппы: вместо каскадного удаления карточек (`ON DELETE CASCADE`), поле `subgroup_slug` теперь устанавливается в `NULL` (`ON DELETE SET NULL`)
- ✅ Колонки `group_slug` и `subgroup_slug` теперь разрешают `NULL` значения
- **Причина:** Сохранение карточек при удалении группы или подгруппы для возможности восстановления или переназначения

## [2025-12-09]

### Изменено
- ✅ Таблица переименована из `items` в `data`
- ✅ Колонка `id` удалена, `slug` стал PRIMARY KEY
- ✅ Колонки `url_1` до `url_6` возвращены к `VARCHAR(500)` (временно были `TEXT`)
- ✅ Колонки `url_seo_yandex` и `url_seo_google` возвращены к `VARCHAR(500)` (временно были `TEXT`)
- ✅ Колонка `version_slug` изменена с `INT` на `VARCHAR(255)` для соответствия `versions.slug`
- ✅ Добавлен внешний ключ `fk_data_version`: `data.version_slug` → `versions.slug` (ON DELETE SET NULL, ON UPDATE CASCADE)
- **Причина:** Удаление `id` для единообразия с таблицами `groups` и `subgroups`. URL были сокращены и больше не превышают 500 символов. Связь с таблицей `versions` для управления версиями элементов

## [2025-12-09] - Первоначальная версия

### Создано
- Таблица `items` создана (позже переименована в `data`)
- Добавлены все поля из `data.json`
- Настроены индексы для быстрого поиска
- Добавлены связи с таблицами `groups` и `subgroups`
- Добавлены поля для SEO оптимизации
- Поддержка до 6 ссылок на ресурсы
- Поля для AI саммари и метаданных

### Особенности
- Автоматические timestamps: `created_at_db`, `updated_at_db`
- Индексы на часто используемые поля для оптимизации запросов
- Поддержка множественных ссылок (url_1 - url_6)
