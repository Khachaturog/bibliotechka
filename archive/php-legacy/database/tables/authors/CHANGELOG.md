# Changelog - Таблица `authors`

## [2025-12-09] - Первоначальная версия

### Создано
- Таблица `authors` создана
- Добавлены поля для хранения информации об авторах
- `slug` как PRIMARY KEY
- Поля для русского и английского названий автора
- Поле для аватара автора
- Автоматические timestamps: `created_at_db`, `updated_at_db`

### Структура
- `slug` - уникальный идентификатор автора (PRIMARY KEY)
- `title_ru` - имя автора на русском языке
- `title_en` - имя автора на английском языке
- `avatar` - путь к аватару автора
