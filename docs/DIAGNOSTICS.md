# Диагностика проблемы: сайт не загружает данные на продакшене

## Шаг 1: Проверка подключения к базе данных

1. **Создайте временный файл `api/test-connection.php`** (см. пример ниже)
2. **Загрузите на сервер**
3. **Откройте в браузере**: `https://ваш-домен.ru/api/test-connection.php`
4. **Проверьте результаты**:
   - ✓ Если подключение успешно → переходите к Шагу 2
   - ✗ Если ошибка подключения → см. раздел "Исправление доступа к БД"

**⚠️ ВАЖНО:** После проверки удалите `api/test-connection.php` из соображений безопасности!

### Исправление доступа к БД

Если видите ошибку подключения к БД:

1. **Узнайте IP-адрес вашего веб-сервера**:
   - Зайдите в панель управления хостингом
   - Найдите информацию о вашем сервере
   - Или используйте команду в SSH: `curl ifconfig.me`

2. **Добавьте IP-адрес сервера в список разрешенных для MySQL**:
   - В панели управления MySQL найдите "Доступ по IP"
   - Добавьте IP-адрес вашего веб-сервера (например: `45.92.174.185`)
   - **НЕ добавляйте `*` или `0.0.0.0/0`** - это небезопасно!

3. **Проверьте настройки подключения в `api/config.php`**:
   ```php
   define('DB_HOST', 'mysql.35401aca832c.hosting.myjino.ru');
   define('DB_USER', 'j35045845_biblio');
   define('DB_PASSWORD', 'tuhrih-zoqmYp');
   define('DB_NAME', 'j35045845_biblio');
   ```
   - Убедитесь, что эти данные правильные для вашего продакшена

## Шаг 2: Проверка работы API

1. **Откройте в браузере**:
   - `https://ваш-домен.ru/api/v1/groups/list`
   - `https://ваш-домен.ru/api/v1/data/list?status_slug=published`

2. **Проверьте результат**:
   - ✓ Если видите JSON с данными → API работает, переходите к Шагу 3
   - ✗ Если видите ошибку 404 или 500 → см. раздел "Исправление API"

### Исправление API

Если API не работает:

1. **Проверьте, включен ли mod_rewrite в Apache**:
   - Обычно включен по умолчанию
   - Если нет, обратитесь в поддержку хостинга

2. **Проверьте файл `.htaccess`**:
   - Убедитесь, что файл `.htaccess` загружен в корень сайта
   - Убедитесь, что файл `api/.htaccess` загружен в папку `api/`

3. **Проверьте права доступа к файлам**:
   - Файлы должны быть доступны для чтения (обычно 644)
   - Папки должны быть доступны для чтения (обычно 755)

4. **Проверьте логи ошибок**:
   - В панели управления хостингом найдите логи ошибок
   - Ищите ошибки PHP или Apache

## Шаг 3: Проверка в консоли браузера

1. **Откройте сайт** в браузере
2. **Откройте Developer Tools** (F12)
3. **Перейдите на вкладку "Network"**
4. **Обновите страницу** (F5)
5. **Проверьте запросы к API**:
   - Найдите запросы к `/api/v1/groups/list` и `/api/v1/data/list`
   - Проверьте статус ответа:
     - **200 OK** → API работает, проблема в JavaScript
     - **404 Not Found** → API не найден, проверьте .htaccess
     - **500 Internal Server Error** → Ошибка в PHP, проверьте логи
     - **CORS error** → Проблема с заголовками CORS

## Шаг 4: Проверка JavaScript

1. **Откройте консоль браузера** (F12 → Console)
2. **Ищите ошибки JavaScript**:
   - Ошибки загрузки файлов (404)
   - Ошибки выполнения кода
   - Ошибки CORS

3. **Проверьте, что файлы загружены**:
   - `js/config.js` - должен быть доступен
   - `js/index.js` - должен быть доступен
   - `js/group.js` - должен быть доступен

## Частые проблемы и решения

### Проблема: "Failed to fetch" или CORS error

**Решение**:
- Проверьте, что в `.htaccess` есть заголовки CORS (они уже есть)
- Убедитесь, что mod_headers включен в Apache

### Проблема: API возвращает 404

**Решение**:
- Проверьте, что файл `api/index.php` существует
- Проверьте, что `.htaccess` правильно настроен
- Попробуйте открыть напрямую: `https://ваш-домен.ru/api/index.php`

### Проблема: База данных пустая

**Решение**:
- Убедитесь, что вы импортировали данные в БД на продакшене
- Проверьте, что таблицы существуют и содержат данные

### Проблема: Данные не отображаются, но API работает

**Решение**:
- Проверьте консоль браузера на ошибки JavaScript
- Проверьте, что все JS файлы загружены
- Проверьте, что `js/config.js` правильно настроен
