# Переиндексация через IndexNow

[IndexNow](https://www.indexnow.org/ru_ru/documentation) позволяет уведомить поисковые системы (Яндекс, Bing и др.) об изменении страниц — индексация происходит быстрее, чем при обычном обходе по sitemap.

## Что сделано

1. **Файл ключа** в корне сайта: `bibliotechka-indexnow-a1b2c3d4.txt`  
   Содержит ключ для проверки права собственности на домен. Файл должен быть доступен по адресу:  
   `https://bibliotechka.online/bibliotechka-indexnow-a1b2c3d4.txt`

2. **Скрипт отправки URL**: `scripts/submit-indexnow.js`  
   Читает URL из `sitemap.xml` и отправляет их в Яндекс и в общий API IndexNow (Bing и др.).

## Как запустить

Из корня проекта:

```bash
npm run submit-indexnow
```

Или с указанием своего sitemap:

```bash
node scripts/submit-indexnow.js path/to/sitemap.xml
```

Перед запуском убедитесь, что:

- сгенерирован актуальный `sitemap.xml` (например, `npm run generate-sitemap`);
- **файл ключа залит на сайт в корень** — по адресу `https://bibliotechka.online/bibliotechka-indexnow-a1b2c3d4.txt` должен открываться текст `bibliotechka-indexnow-a1b2c3d4`. Без этого поисковики не примут отправку (202/403). После деплоя ключа можно снова запустить скрипт.

## Ответы API

- **200** — URL приняты.
- **202** — запрос принят, ключ ещё проверяется (можно повторить позже).
- **403** — ключ не прошёл проверку (файл ключа недоступен или содержимое не совпадает).
- **429** — слишком частые запросы, подождите перед повторной отправкой.

Переиндексация по IndexNow не гарантирует немедленное появление страниц в выдаче, но ускоряет учёт изменений.
