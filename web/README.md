# web — Библиотечка (Vite + React)

Frontend for [bibliotechka.site](https://bibliotechka.site).

- Base UI Dialog/Drawer (nav sidepage + bottom sheet on mobile)
- Lucide icons
- Spotlight free-text search + group/subgroup chip mode
- Mono card typography (`IBM Plex Mono`)
- `VITE_BASE=/` for domain root (see root README)

```bash
npm install
npm run fetch-content
npm run dev
```
