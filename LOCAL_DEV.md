# Локальная разработка

## 📱 Просмотр с телефона

### Ваш IP адрес в локальной сети: `192.168.1.76`

### Способ 1: PHP встроенный сервер (рекомендуется)

**Требования:** PHP 7.4+ должен быть установлен

```bash
# Установка PHP (если не установлен)
brew install php

# Запуск сервера
./start-api.sh

# Или вручную:
php -S 0.0.0.0:8000 -t . api/index.php
```

**URL для доступа:**
- На компьютере: `http://localhost:8000`
- На телефоне: `http://192.168.1.76:8000`

⚠️ **Важно:** Телефон должен быть подключен к той же Wi-Fi сети, что и компьютер!

### Способ 2: Python HTTP сервер (только статика)

Если PHP не установлен, можно использовать Python для просмотра статических файлов:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

**URL для доступа:**
- На компьютере: `http://localhost:8000`
- На телефоне: `http://192.168.1.76:8000`

⚠️ **Ограничение:** API не будет работать, только статические HTML/CSS/JS файлы.

### Способ 3: Live Server (VS Code/Cursor)

Если используете VS Code или Cursor:

1. Установите расширение "Live Server"
2. Откройте `index.html`
3. Нажмите "Go Live"
4. В настройках Live Server укажите `0.0.0.0` вместо `localhost`
5. Откройте на телефоне: `http://192.168.1.76:5500` (или другой порт)

## 🔧 Проверка подключения

### Узнать свой IP адрес:

**macOS:**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
# или
ipconfig getifaddr en0
```

**Linux:**
```bash
hostname -I
# или
ip addr show
```

**Windows:**
```bash
ipconfig
# Найдите IPv4 адрес
```

## ⚠️ Решение проблем

### Не могу подключиться с телефона

1. **Проверьте Wi-Fi:** Телефон и компьютер должны быть в одной сети
2. **Проверьте файрвол:** Разрешите входящие подключения на порт 8000
3. **Проверьте IP адрес:** Убедитесь, что используете правильный IP
4. **Проверьте сервер:** Убедитесь, что сервер запущен и слушает `0.0.0.0`, а не только `localhost`

### API не работает

- Убедитесь, что используете PHP сервер, а не Python
- Проверьте, что PHP может подключиться к серверной БД (проверьте настройки в `api/config.php`)
- Проверьте логи сервера на наличие ошибок

### Ошибка "Connection refused"

- Убедитесь, что сервер запущен
- Проверьте, что порт 8000 не занят другим приложением
- Попробуйте другой порт: `php -S 0.0.0.0:8080 -t . api/index.php`
